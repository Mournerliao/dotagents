# Pi extensions

Original [pi](https://pi.dev) extensions live here. `pi/` is a store, not an npm package. Each subdirectory is one pi package and is published independently.

| Package | npm | Install from checkout |
|---------|-----|------------------------|
| [cursor-provider](cursor-provider/) | [`@mournerliao/pi-cursor-provider`](https://www.npmjs.com/package/@mournerliao/pi-cursor-provider) | `pi install "$(pwd)/pi/cursor-provider"` |

Install with `pi install`, not the skills CLI.
