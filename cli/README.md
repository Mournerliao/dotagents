# @mournerliao/agent-skills

Personal capability library CLI. This package is the `cli/` directory of [dotagents](https://github.com/Mournerliao/dotagents).

```bash
npx @mournerliao/agent-skills list
```

Requires Node.js 20+. Global binary: `agent-skills`.
