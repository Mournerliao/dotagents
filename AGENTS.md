## dotagents

Personal collection of AI and agent resources. The skills CLI is the `cli/` package (`@mournerliao/agent-skills`).

### Issue tracker

Issues and PRDs are tracked in GitHub Issues. External pull requests are not a triage request surface. See `docs/agents/issue-tracker.md`.

### Triage labels

The repository uses the default five-role triage label vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

The repository uses a single-context domain documentation layout. See `docs/agents/domain.md`.
